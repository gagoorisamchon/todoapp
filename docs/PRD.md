# 할 일 관리 앱 PRD

## 1. Why - 목적
- 일일 할 일, 주간 계획, 1년 목표를 하나의 구조로 연결
- 오늘 하는 일이 연간 목표에 어떻게 기여하는지 확인
- 상태와 진행률을 수동으로 관리하는 부담 제거

## 2. Who - 타깃 사용자
- 연간 목표를 주간·일일 단위로 쪼개 실행하는 개인 사용자
- 할 일 상태를 칸반 방식으로 관리하려는 사용자
- 주간 단위로 진척도를 점검하는 사용자

## 3. User Flow
1. 1년 목표 생성
2. 주간 계획 생성 → 1년 목표에 연결
3. 일일 할 일 생성 → 주간 계획에 연결
4. 칸반 보드(todo / doing / done)에서 할 일 확인
5. 드래그앤드롭으로 상태 변경
6. 주간 진행률 자동 갱신
7. 주간 계획 → 1년 목표 순으로 진척 확인

## 4. 기능요구사항

### P0 - 핵심기능
- **할 일 CRUD**
  - 생성: 제목(필수), 날짜(필수), 연결할 주간 계획(선택)
  - 수정: 제목, 날짜, 상태, 연결 주간 계획
  - 삭제: 삭제 전 확인 → 삭제 시 주간 진행률 재계산
- **상태관리**
  - 상태값: `todo` / `doing` / `done`
  - 생성 시 기본값: `todo`
  - 할 일 1개 = 상태 1개
- **드래그앤드롭 상태 변경**
  - 칸반 보드에 상태별 컬럼 3개
  - 다른 컬럼으로 이동 시 상태 변경
  - 변경 즉시 저장
- **기간 구조**
  - 일일: 할 일 (날짜 단위)
  - 주간: 주간 계획 (주 단위, 시작일~종료일)
  - 연간: 1년 목표 (연도 단위)
  - 주간 계획·1년 목표 각각 CRUD 지원
- **구조 연결**
  - 할 일 → 주간 계획: N:1
  - 주간 계획 → 1년 목표: N:1
  - 할 일 날짜는 연결된 주간 계획 기간 안에 있어야 함
  - 상위 항목 삭제 시 하위 항목은 연결만 해제 (삭제하지 않음)
- **주간 진행률 자동 반영**
  - 계산식: `done` 할 일 수 ÷ 연결된 할 일 수 × 100
  - 갱신 시점: 할 일 생성·수정·삭제, 상태 변경, 연결 변경
  - 연결된 할 일이 0개면 0% 표시

### P1 - 추가기능
- 1년 목표 진행률 표시 (연결된 주간 계획의 진행률 평균)
- 주간 계획에 연결되지 않은 할 일 별도 표시
- 기간별 뷰 전환 (일일 / 주간 / 1년)
- 미완료 할 일 다음 주 주간 계획으로 이월
